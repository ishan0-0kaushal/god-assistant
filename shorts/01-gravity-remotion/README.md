# Short 01 — Gravity doubles every second (Remotion)

Script: [../scripts/01-gravity-doubles.md](../scripts/01-gravity-doubles.md)

## Render

```bash
npm install
REMOTION_BROWSER_EXECUTABLE=/path/to/chrome-headless-shell npx remotion render Gravity out/gravity.mp4
```

`REMOTION_BROWSER_EXECUTABLE` is only needed where Remotion can't download its own Chrome (the cloud
container uses `/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`).
A 30 s render takes about 1m40s on 4 cores (PNG frames, CRF 15, slow preset, BT.709; see `remotion.config.ts`). `./scripts/stills.sh <frames...>` renders review stills
and `./scripts/sheet.sh` tiles them.

## Where things live

- `src/timeline.ts` — every beat's start/end, VO line and sim-clock value. Everything on screen keys off
  this table, so retiming to the voiceover is a change to this file only.
- `src/Gravity.tsx` — scene logic (stickman, ghost, scale, planet, overlays).
- `src/ladder.ts` — when each object drops onto the scale and gets launched.
- `src/components/` — stickman rig, counter bar / light bar / captions, balance scale, object
  silhouettes, ground, planet / black hole.
- `src/Sfx.tsx` + `public/sfx/` — placeholder sound effects, generated by `scripts/make-sfx.sh`.
