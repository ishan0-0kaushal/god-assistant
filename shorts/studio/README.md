# Actually Animated studio (HyperFrames)

One HyperFrames project for every short, built on a shared style kit that matches the channel's look
(see [../STYLE.md](../STYLE.md)).

## Build and render

```bash
npm install            # postinstall copies GSAP and the fonts locally
npm run build          # src/*.html + src/*.timing.json -> dist/<name>/index.html
HYPERFRAMES_BROWSER_PATH=/path/to/chrome-headless-shell \
  npx hyperframes render dist/gravity -o out/gravity.mp4 --quality high
npx hyperframes snapshot dist/gravity --at 3,10,20   # review frames + contact sheet
```

`HYPERFRAMES_BROWSER_PATH` is only needed where HyperFrames can't download its own Chrome (the cloud
container uses `/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`). A 30 s
short renders in about 2 minutes on 4 cores.

## Layout

- `kit/kit.css`: color tokens, type, tracker pills, counters, pills, chips, tags, stamps, shouts,
  comparison bars, captions.
- `kit/kit.js`: dot-matrix globe (real land data) with zoom from planet to ground, latitude rings,
  black hole, background streaks / stars / clouds, particle bursts, the stickman rig with afterimage
  trails, the tracker HUD and word-by-word captions. Everything is a pure function of time.
- `kit/land-dots.js`: generated by `npm run land` from world-atlas.
- `src/<name>.html`: one short's scenes. `render(t)` draws the frame for time `t`.
- `src/<name>.timing.json`: **the only place timing lives**: scene beats, caption lines (with
  `*emphasis*` words and an accent color) and sound cues.
- `assets/sfx/`: placeholder sound effects from `scripts/make-sfx.sh`.

## Adding the voiceover

1. Generate each caption line with ElevenLabs' timestamps endpoint (reads `ELEVENLABS_API_KEY` and
   `ELEVENLABS_VOICE_ID`; the environment must allow `api.elevenlabs.io`).
2. In the timing file, set each line's `start`/`end` and a `words` array of per-word start times
   from the alignment, move the scene beats to match, and add `"vo": "assets/vo/<name>.mp3"`.
3. `npm run build` and render. Captions then reveal word by word in sync with the voice.

## Adding a short

Copy a `src/*.html` + `src/*.timing.json` pair, keep the kit components, and write new scenes in
`render(t)`. `npm run build <name>` builds just that one.
