# Short 02 — Falling from every height (HyperFrames)

Script: [../scripts/02-fall-from-every-height.md](../scripts/02-fall-from-every-height.md)

## Render

```bash
npm install   # postinstall copies GSAP and the fonts into vendor/ and assets/fonts/
HYPERFRAMES_BROWSER_PATH=/path/to/chrome-headless-shell npx hyperframes render -o out/falling.mp4 --quality high
```

GSAP and the fonts are served locally because the default CDN isn't reachable from the cloud
container. `HYPERFRAMES_BROWSER_PATH` is only needed where HyperFrames can't download its own Chrome.
A 30 s render takes about 85 s. `npx hyperframes snapshot . --at 3,10,20` captures review frames.

`npx hyperframes lint .` reports 0 errors. The 32 warnings are Studio-editor hints (missing editable
ids, scenes not split into sub-compositions); they don't affect renders.

## Where things live

Everything is in `index.html`:

- Scenes, callouts, captions and sound effects are clips with `data-start` / `data-duration`.
- `render(t)` in the script block computes the counters, speedometer, sky, clouds, faller, ISS orbit
  and transitions from the current time; GSAP drives the ground-drop moves and the pop-ins.
- Retiming to the voiceover means editing the `data-start` values and the times inside `render(t)`
  and the GSAP calls; there is no single timing table like the Remotion version has.
- `assets/sfx/` — placeholder sound effects, generated by `scripts/make-sfx.sh`.
